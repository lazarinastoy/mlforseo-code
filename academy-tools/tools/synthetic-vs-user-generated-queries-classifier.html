Synthetic vs User-generated Queries Classifier

Tell the short queries people type apart from the longer, denser ones AI search generates, with feature extraction, a rule-based score and a weighted model. Runs entirely in your browser.

Feature extraction

See the signals both classifiers read: length, stop words, entities, reading grade, question words and technical vocabulary.
One query per line, or a column named keyword or query.
Entities are found by capital letters (any word after the first) plus a short list of known names such as Google, iPhone and Python. Keyword exports in all lower case will under-count them.

Rule-based classifier

Seven readable rules add points to a synthetic score out of 8.5. A query that reaches the classification threshold is labelled synthetic.
One query per line, or a column named keyword or query.

Classification rules

Points: 1 for a long query, 1 for stop words under 20%, 2 for a reading grade above the threshold, 2 for entity density above the threshold, 1 for any technical term, 0.5 for no question word in a query of four or more words, 1 for two or more entities. Changing a value re-runs the result on screen.

ML classifier

A weighted model scores eight normalised features together and returns the probability that a query is synthetic. A question word cuts the probability by 30%.
One query per line, or a column named keyword or query.

Model configuration

A query is labelled synthetic when its probability reaches this value. Lower it to flag more queries as synthetic, raise it to flag fewer.
The weights are fixed in the tool, not learned from your data. Use it to sort and sample a keyword list, then check a handful of each label by eye.

What to do with the split

User queries are demand

They are what people actually type. Treat them as direct traffic targets and answer them plainly.

Synthetic queries are expansion

They show how AI search breaks one question into many. Covering them makes your page a source an answer can cite.

Each needs different content

Short, direct pages suit user queries. Synthetic ones reward depth, definitions and clearly named entities.

Compare, then prioritise
